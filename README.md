## FAQ

### What exactly is XCutors?

XCutors is an open-source collection that bundles several popular Roblox executor engines—Volt, Synapse Z, Potassium, and Wave—along with a universal loader called xcutorsLoader, all accessible from a single Windows desktop application.

### Is XCutors free to use?

Yes. The XCutors collection and its universal loader are completely free and open-source. Individual executor engines may have their own licensing terms; check each engine's documentation for details.

### What operating systems are supported?

XCutors is designed exclusively for Windows. Windows 10 (version 1903 or later) and Windows 11 are officially supported. Compatibility with older versions such as Windows 7/8 is not guaranteed.

### How do I switch between executor engines?

Open the Settings tab in xcutorsLoader, select the desired engine (Volt, Synapse Z, Potassium, or Wave) from the dropdown menu, and click Apply. The loader will reinitialize with the chosen engine on the next attach cycle.

### Why does my anticomponent flag the application?

Some anticomponent heuristics flag executor-related software because of memory-injection techniques used to interface with game clients. XCutors is fully open-source—review the code yourself, whitelist the folder in your security software, or build from source for full transparency.

### Can I add my own custom Lua scripts?

Absolutely. Paste any valid Roblox-compatible Lua code into the built-in editor or load a saved .lua file from disk using the "Open Script" button. You can also save scripts to the library for quick access later.

### Where can I get help or report a bug?

Open an issue on this GitHub repository with a detailed description and steps to reproduce. You can also join the community Discord server linked in the repository description for real-time support from other users and maintainers.

### Will XCutors work on Roblox mobile or console?

No. XCutors is a Windows desktop tool and requires the Windows version of the Roblox client. It does not support Roblox on mobile devices, macOS, consoles, or any cloud gaming variant.

### How do I update to a newer version?

Check the Releases page periodically or enable the built-in auto-check feature in Settings. When a new version is available, download the ZIP, replace your existing files, and relaunch xcutorsLoader.
